# Week 01: Navigate the Linux filesystem

**Objective:** Use `pwd`, `ls -la`, `mkdir`, `cd`, `touch` to create an organized workspace.

## In-class practice

1. Instructor demonstrates the concept on a disposable sample repository or directory.
2. You repeat the task, explain each command to a partner, and inspect the actual result.
3. You intentionally make one safe, reversible error and recover.

## Homework

Show evidence that you understand the outcome, using your own fork or project.

## Auto-checked command worksheet

Copy `templates/week01/answers.json` to `submissions/YOUR_USERNAME/week01/answers.json` in your fork, fill in all five command strings, then commit and push. Public checks accept a small set of correct command forms; in a real shell many equivalent commands exist. Be prepared to demonstrate them live.
