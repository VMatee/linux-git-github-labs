# Week 12: Team integration

**Objective:** Merge tested pull requests, update the team README, and link evidence of code review.

## In-class practice

1. Instructor demonstrates the concept on a disposable sample repository or directory.
2. You repeat the task, explain each command to a partner, and inspect the actual result.
3. You intentionally make one safe, reversible error and recover.

## Homework

Show evidence that you understand the outcome, using your own fork or project.

## Evidence for human review

Include links to your own GitHub commits, Pull Requests, workflows, or project README when requested. Never publish private information or grades.

## Reflection

In your own words, explain why this practice makes collaboration safer or more reproducible.
