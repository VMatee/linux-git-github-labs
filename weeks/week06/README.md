# Week 06: GitHub remotes

**Objective:** Clone a public repository, add a remote, fetch, push, and pull safely.

## In-class practice

1. Instructor demonstrates the concept on a disposable sample repository or directory.
2. You repeat the task, explain each command to a partner, and inspect the actual result.
3. You intentionally make one safe, reversible error and recover.

## Homework

Show evidence that you understand the outcome, using your own fork or project.

## Auto-checked command worksheet

Copy `templates/week06/answers.json` to `submissions/YOUR_USERNAME/week06/answers.json` in your fork, fill in all five command strings, then commit and push. Public checks accept a small set of correct command forms; in a real shell many equivalent commands exist. Be prepared to demonstrate them live.

## Reflection

In your own words, explain why this practice makes collaboration safer or more reproducible.
