# Week 04: First local Git repository

> **Your terminal:** On Windows use **Ubuntu in [WSL2](../../docs/setup/windows-wsl2.md)**; on Ubuntu Linux use the **native Ubuntu Terminal**. All commands in this lesson run inside Ubuntu. [Setup checklist](../../docs/setup/README.md).

**Objective:** Initialize a Git repository. Stage a Python program, commit, and inspect the history.

## In-class practice

1. Instructor demonstrates the concept on a disposable sample repository or directory.
2. You repeat the task, explain each command to a partner, and inspect the actual result.
3. You intentionally make one safe, reversible error and recover.

## Homework

Show evidence that you understand the outcome, using your own fork or project.

## Auto-checked command worksheet

Copy `templates/week04/answers.json` to `submissions/YOUR_USERNAME/week04/answers.json` in your fork, fill in all five command strings, then commit and push. Public checks accept a small set of correct command forms; in a real shell many equivalent commands exist. Be prepared to demonstrate them live.
