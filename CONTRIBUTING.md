# Contributing

Thanks for helping make these labs more useful. Improvements to examples, spelling, documentation, accessibility, and reproducibility are welcome.

1. Search existing issues for the same problem.
2. Open an issue explaining the expected behavior and the smallest steps to reproduce it.
3. Fork the repository, create a descriptive branch, and change only relevant files.
4. Run any applicable checks, then open a pull request with a short summary and evidence.

Please keep class-specific homework submissions in **your own fork**, not in pull requests to this main course repository. Do not share credentials, student IDs, private classroom data, or other people's personal information.

Be constructive in review discussions. Following, starring, and forking are optional.
